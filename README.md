# Nous Research · Purple Instrument Theme

This bundle starts from the original theme files and adds only the focused
Nous Research surfaces: animated window outlines, dark compositor panels, a
thin flat Waybar layout, smooth terminal caret motion, custom folder icons, a
restored dark-purple field background, and a high-detail Fastfetch portal
figure rendered from the supplied artwork in the original palette.

Run `./install.sh` to install and select the theme. The wallpaper is selected
from `backgrounds/nous-purple-field.png`; the original Waybar color source
`waybar.css` is intentionally unchanged.

The Fastfetch portal figure can be regenerated with:

```bash
./scripts/render-fastfetch-logo.sh
```
